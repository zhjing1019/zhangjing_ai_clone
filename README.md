# Self-AI-Agent 个人AI复制体
复刻本人说话语气、口头禅、思维逻辑的 Python AI Agent，基于 DeepSeek 接口开发。

## 项目特性
- ✅ 完全复刻个人说话风格与思维逻辑
- ✅ 支持多轮上下文连续对话
- ✅ 重启程序自动加载历史会话，记忆不丢失
- ✅ 自动保存带时间戳完整聊天日志
- ✅ 输入 clear 一键清空会话记忆
- ✅ 独立 Python 虚拟环境，环境隔离干净
- ✅ 密钥与虚拟环境已加入 .gitignore，安全不上传 GitHub

## 技术栈
- Python 3.x
- DeepSeek API（兼容 OpenAI 接口格式）
- python-dotenv 环境变量管理
